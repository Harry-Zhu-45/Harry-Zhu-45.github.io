## 简介

- 免费使用
- 文件保存在本地，文件格式为 Markdown 文档，可迁移
- 支持双向链接
- 拥有 cli 支持，agent 可以操作 Obsidian

## 插件学习

> 不要老是想着 all in Obsidian

- Excalidraw
  - 可以画图，经常更新
- Mind Map
  - 可以生成思维导图，便于查看大纲
- Pandoc Plugin
  - 调用了 Pandoc，用来生成 PPT 等格式的文件
- Note Refactor
  - 将大文档根据标题切分成小文档，并在大小文档之间建立链接
- dataview
  - 把 Obsidian 变成数据库使用
- Footnote shortcut
  - 可以使用快捷键在文段中加入角标注释
- Tiny Footnotes
  - 可以将文段中乱序的角标重新排序
- Advanced URI
  - 用 uid 代替文件路径生成稳定的外链
- Citations
  - 通过 BibLaTeX 的 bib 文件生成引文
